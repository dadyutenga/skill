# OpenDashboards design

Agent skill for the OpenDashboards visual system: dashboard tokens, app chrome, and marketing buttons.

The instructions are in [SKILL.md](SKILL.md). The tokens are in [assets/tokens.css](assets/tokens.css), the component recipes in [assets/components.css](assets/components.css), and the same values as JSON in [assets/tokens.json](assets/tokens.json).

Token values come from [OpenDashboards](https://github.com/thesysdev/opendashboards) and `@openuidev/dashboard-library`, both MIT, © Thesys Inc.
